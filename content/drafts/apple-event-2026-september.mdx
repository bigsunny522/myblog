## 折りたたみiPhone iPhone Ultra

今回の最大の目玉。Appleにとって初の折りたたみスマートフォンです。名称は **iPhone Ultra** が有力とされていますが、iPhone Fold の可能性も残っています。

### 事前予想されていたスペック

| 項目 | 噂されていた内容 |
| --- | --- |
| 形状 | ブック型（横開き） |
| 外側ディスプレイ | 約5.5インチ OLED |
| 内側ディスプレイ | 約7.8インチ OLED |
| 厚さ | 開いた状態で約4.5mm、閉じた状態で約9mm |
| ヒンジ | リキッドメタル採用で折り目を最小化 |
| 生体認証 | Face ID非搭載、サイドボタンのTouch ID |
| チップ | 2nmプロセスの A20 Pro（7コアGPU） |
| メモリ | 12GB |
| カメラ | 背面デュアル（広角＋超広角、望遠なし）、内外に前面カメラ |
| バッテリー | 5,400〜5,800mAh |
| モデム | Apple製 C2 |
| カラー | シルバー系とディープインディゴ |
| 価格 | 2,000ドル〜（上位構成は2,500ドル超との観測も） |

日本での価格は、為替と最近のApple製品の価格設定から **35万〜40万円台** になるという予想が複数のメディアで出ていました。この予想が当たるかどうかは、発表後の日本のApple Storeの価格表示で確認します。

ソフト面では、iPadに近い**サイドバー表示や2画面のマルチタスク**に対応するとされていました。折りたたんだ状態と開いた状態でアプリのレイアウトがどう切り替わるのかは、実機デモで一番見たいポイントです。

## iPhone 18 Pro と iPhone 18 Pro Max

外観は iPhone 17 Pro を踏襲しつつ、中身を大きく変えてくると見られています。

### 事前予想されていた変更点

- **可変絞り** — メインカメラに機械式の可変絞りを搭載。背景ボケや明るさのコントロール幅が広がる
- **3層積層センサー** — Samsung製の3層積層イメージセンサーを採用し、ダイナミックレンジを改善
- **A20 Proチップ** — 2nmプロセス。A19 Pro比で約18%高速、電力効率は最大30%改善との観測
- **LTPO+ディスプレイ** — 現行OLEDより省電力な新世代パネル
- **Dynamic Islandの小型化** — 一部センサーをディスプレイ下に移動して面積を縮小
- **バッテリー増量** — Pro Max は5,567mAh。本体はわずかに厚く・重くなる可能性
- **新色** — ダークチェリー、ライトブルー、シルバー。**ブラックは廃止**との噂
- **カメラコントロールボタンの簡素化**

なお「ディスプレイ内蔵Face ID」については、**今年から搭載されるという説と、2027年以降にずれるという説の両方が出ていました。** ここは発表を見るまで確度が低い部分です。

価格については、iPhone 17 Pro から **100〜300ドルの値上げ**を予想する声がありました。日本価格は為替の影響も受けるため、ここも要確認です。

予約開始は9月12日（土）午前5時（PT）、発売は9月18日という予想が出ていました。9月11日を避けた日程だと見られています。

## Apple TV と HomePod と 新型ホームハブ

ここは「出るかもしれない」枠です。

- **新型ホームハブ** — 7インチのスクエア型ディスプレイ。カメラと人感検知を内蔵し、スマートホーム操作・ビデオ通話・Siri連携に対応するとされる新カテゴリ製品

## iOS 27 など OS の配信日

イベントでは、WWDC26で発表済みの各OSの正式リリース日がアナウンスされる見込みです。

- iOS 27 / iPadOS 27
- macOS 27（Golden Gate）

配信日は **9月14〜15日あたり** と予想されています。iOS 27 の目玉は刷新された **Siri**。より自然な対話、画面内容の認識、アプリをまたいだ操作に対応するとされ、Dynamic Island からの呼び出しにも対応すると報じられていました。あわせて、アプリ起動やPhotosの読み込み速度などの**パフォーマンス改善**も大きく打ち出されています。
